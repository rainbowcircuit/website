Frequently Asked Questions

Installing a Max for Live Device

Unzip the download, then move the .amxd file into the folder that matches the device type:

  • Instrument: Ableton/User Library/Presets/Instruments/Max Instrument
  • Audio Effect: Ableton/User Library/Presets/Audio Effects/Max Audio Effect
  • MIDI Effect: Ableton/User Library/Presets/MIDI Effects/Max MIDI Effect

Device Graphics Looks Incorrect

This is usually caused by an outdated version of Max.

Download and install the latest version from cycling74.com, then in Ableton go to Settings → File & Folder and set the Max Application path to the newly installed version.

Restart Ableton for the change to take effect.
